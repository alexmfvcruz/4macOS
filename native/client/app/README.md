# Native client executable (C4)

`build.py` builds `4story-client`, the original TClient for macOS ARM64, from
the original units and the native layers, and links it with DXVK Native
(Direct3D 9 → Vulkan), MoltenVK and SDL3 (C3 option C). `run.py` starts it.

```
python3 native/client/app/build.py [--sanitize] [--keep-going] [--compile-only] [--channel beta|dev|stable] [--version 0.1]
python3 native/client/app/run.py --plain --seconds 60 --capture 2000 --screen 1280x800 \
    [--input native/client/app/scripts/login-text.txt] [-- 127.0.0.1 4815 1]
```

Output: `build/client/c4-plain/` (default) or, with `--sanitize`,
`c4-sanitized/` (ASan/UBSan). `run.py` starts `c4-sanitized` unless `--plain`
is given. Runs: `runtime/client/runs/<time>/` (log, status, captures).
Dependencies: the approved local SDL3, DXVK, MoltenVK and Vulkan SDK builds
of C3 under `deps` (paths in `native/client/deps.py`;
`FOURSTORY_SDL3_PREFIX` and `FOURSTORY_DXVK_D3D9` override them for the build). Nothing is downloaded or installed.

## What is built

| Part | Units |
| --- | --- |
| Engine Lib | every unit of `Engine Lib.vcxproj` except the replaced ones below |
| TComp, TChart, TCML | every unit except the Internet Explorer units |
| HwidLib | `__Sha256.cpp` only |
| TClient | every unit of `TClient.vcxproj` except the list below |
| Compatibility | `native/client/compat/src` (Win32, MFC, GDI, GDI+, kernel32) |
| Shell | `native/client/shell/src` (SDL3 backend, stand-ins) |
| App | `src/` (entry point, D3DX shader table, replacements, capture) and the generated resource and shader tables (`gen_resources.py`) |

Defines: `FOURSTORY_CLIENT_NATIVE`, `FOURSTORY_CLIENT_64`,
`FOURSTORY_CLIENT_MOD` and the Release x64 definitions of
`TClient.vcxproj:303` (`NEW_IF`, `USE_HWID_AUTH`, `NDEBUG`). Not defined:
`FOURSTORY_CLIENT_NATIVE_LOADER` (only the C1/C2/C3 programs without window
and renderer define it; it selects their stand-ins).

## Resources

`gen_resources.py` turns `TClient.rc` into a table for
`fourstory::resources` (compat `fourstory_kernel32.h`): SHADER and TEXT
files, CURSOR (RIFF files as RT_ANICURSOR, as the resource compiler does),
ICON and STRINGTABLE. DIALOG, VERSIONINFO, accelerators and the MFC string
resources of `afxres.rc` are not generated. `D3DXAssembleShader` looks the
shader source up by SHA-256 in the bytecode that the original D3DX9_43.dll
produced (`native/client/reference/shaders`); other sources fail.

## Test hooks

Both are inactive unless their variable is set.

- `FOURSTORY_C4_CAPTURE_DIR`, `FOURSTORY_C4_CAPTURE_EVERY_MS`: back-buffer
  readback before the three original Present calls, written as PPM
  (`src/capture_native.cpp`).
- `FOURSTORY_C4_INPUT_SCRIPT`: timed input in the SDL backend
  (`shell/src/sdl_backend.cpp`): Win32-level `click`, `move`, `text`, `key`,
  `focus`, `resize`, and real SDL window operations `window-size`,
  `minimize`, `restore`. Scripts: `scripts/`.

Key events from the macOS input system (HID, window server) are not
generated by these hooks; posting them needs the Accessibility permission.

## Audio (C7)

The Game settings list has **Spatial audio (headphones)** beside Interface scale
and Font. Off uses stereo direction and distance; On uses Apple's supported
HRTF/HRTFHQ rendering for mono positional effects. Music, UI sounds without a
position, and stereo WAV assets keep their normal layout. The preference is
saved as Settings/SpatialAudio and defaults to Off. This does not enable head
tracking. In-game listening and placement validation are pending user testing.

See [audio tests and implementation](../audio/README.md) and
[C7 completion evidence](../../../research/c7-completion.md).
